## Before

Twelve folders, each named after whatever project I was on when I made it. Notes filed by mood. Search worked, which was the problem, because it meant I never had to fix anything.

## The refactor

I flattened everything into one folder and gave every note exactly one `kind` field. The kinds were: note, decision, person, source. Four. Not twelve.

## After

Linking got easier because there was less to think about. The model got better at filing because there was less to guess. And the twelve old folder names turned out to be tags, which is what they always were.
